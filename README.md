## 1. 项目与作者

- **作品**：《末世清风》，末世 + 重生流网文。主角陈豆（豆仔）重生回 2018 年高考前一个月，末世比他记忆中提前两年降临。
- **作者**：多年书虫，但自称**写作小白**——需要你主动引导、提供方案和判断，而不是只做记录员。
- **写作方式**：**agent 主笔，作者微调**。所以 canon 文件必须准确、完整，它们是 agent 写作的唯一依据。
- **写作习惯（作者 2026-10-22 要求，新写正文照此）**：提到或释放技能时，技能名用**单引号**，如‘凝爆’，不用双引号、也不省略引号（第10、11章已是这样写的）。另：**不要使用破折号“——”**（作者 2026-10-22 明确要求，AI 味太重，聊天回复和所有生成的文字都包括在内）；文风贴近作者的网文口语，句子朴素，不要写得工整，不要总结式的金句；作者要求"三两句话"就只写三两句，补写内容宜短。**‘屏蔽’（王自在）不是隐身**：别人能看到他，只是会下意识忽略他的存在，只对他自己有效，只持续几秒。 **分场符（作者 2026-10-23 点明的习惯）**：同一章内出现大的镜头切换（例如从陈豆主线切到旺仔支线，或从一个人的视角切到另一个人的视角）时，单独一行写“。。。”隔开；如果镜头切换正好跨章节，下一章开头自然切换，就**不写**分隔符。第16、17章都是这样写的。【观察】第5章末（第959行）和第10章末（第1741行）各有一个章末“。。。”，与这条习惯不一致，是否删去待作者定。 **剧情节奏（作者 2026-10-23）**：一章里不要塞太多事件，进展宁可慢一点。第18章《借电话》我原本写了四场，作者读后把最后一场（石头亮相、"晶核"、决定去宝吉市初级中学、章末复读生缩手）整段删掉，理由是"剧情进展太快"，章末停在老板娘开门后旺仔拿饮料给大家；删后站点口径约 2136 字，比前几章（3400 到 3600）短，作者没有要求补字数。新写旺仔线时，一章只办一两件事，把一件事写透再往下走。 **作者改稿里看出来的毛病（2026-10-23，第18章两轮改稿）**：①对话太短太冷，像在耍酷，作者会补成正常人说话："十二点整"改"昨晚十二点整"，"半包。"改"对，就半包。"，"一人半包"前补"我们商量过"、后补"一直等到救援人员来了为止"（普通人此时还在等救援，要写出人物的盘算）。②一句话单独成段太多，作者会把反应并回同一段："没人回答她。"并成"……？”但是压根没人回答她。"③压缩出歧义："让人咬了"改"让那些怪物咬了"，用人物自己的叫法（怪物、鬼东西）。④视角不要守得太死：别人视角里作者照样叫"旺仔"，不用"少年""男孩"绕开。⑤同一个标签别重复："心里嘀咕着"连用三次，作者改成"心想"。⑥第一轮还有：剧情塞太多、比喻偏文学（"像劈进一截湿木头"）、心理总结句（"只觉得被人替了"）、内心话写成段子堆，作者都删了。
- **创作初衷（作者原话要点）**：
  1. 这是作者**几个现实中真实损友**在末世中求生冒险的"幻想"故事。其他人物可以随意发挥，但**几个主要主角必须符合现实人物设定**，后续作者会继续补充他们的现实特质。
  2. 故事起点是现实世界突发末世；整体类似"灵气复苏"带来全球进化，**缓慢演化**，世界观逐渐变成"修仙玄幻世界"，到接近结尾才完成转变。**结局是主角几人从现实世界的普通人，成为修仙世界后世眼中"创世之初的传说"**，要有史诗感。

## 2. 已拍板的核心决策（速查；以 大纲.md 为准，有冲突以 大纲.md 为准）

- **本书是一部修仙世界的"前传"**：主线是**"秩序的崩塌与重建"**。主角几人因参与并深刻影响了秩序/规则的构建，成为**历史记载**中的人物（不是神话，不是信仰）。
- **结局画面**："秩序已成"——一切秩序建立、规则完善，恰好能衔接某部修仙小说的开头。
- **主角几人全员活到最后**（长寿由境界提升带来）。
- **时间跨度**：千年到万年量级。叙事密度越往后越疏：阶段一逐日逐夜地写，后面的阶段靠时间跳跃。
- **体量**：长篇，字数不重要，故事讲好最重要。
- **叙事人称**：贴着陈豆的第三人称限知（注意：既有正文里有商机/旺仔等分线视角，如何统一是**待讨论项**，见 WORKFLOW 路线图第 8 项）。
- **境界**：暂定共九阶；阶位颜色一阶紫、二阶蓝、三阶青、四阶绿，五阶起未定。
- **"清风"**：商机命名；是**精英小队**（核心几人到十人，战力很高），**不是大型幸存者组织**，**不会在阶段二成立**，成立时间更靠后。
- **阶段一《崩塌》**（约数月）：
  - 陈豆+选手线：**起点龙骨村**（不是副本；2026-10-22 作者拍板）→ 三个副本：**小钟山**（途经的小村镇，含五里镇——五里镇建在小钟山范围内，同属这一个副本；第一个副本，内容待补）→ **康安市区**（人类幸存者勾心斗角，粗糙小队组织）→ **秦岭**（大量进化兽）。三个副本分别展示崩塌的"个体 / 社会 / 自然"三个层面。
  - 主轴：陈豆（重生者）帮助选手（善良、刚成年、不适应）适应末世残酷。
  - 各人互相认定对方会先回夕海，这是行动的"主线任务"，但**不会**以夕海会合作为阶段一结尾。
  - 商机+胖子在**秦岭**与陈豆+选手阴差阳错地会合。到秦岭时几人约二阶巅峰~三阶初期。
  - 小雪被大鸟叼往秦岭是刻意埋的伏笔，秦岭副本呼应，但陈豆选手**不是为救小雪才走秦岭**（巧合），作用是继续完成选手的心理蜕变。
- **商机+胖子线（阶段一）**：起点商络市（口语"商洛"，同一地名）：商络市区**中型副本**（两人升到二阶）→ **两个小副本**（商络途经秦岭的村镇，小龙在第一个登场）→ **秦岭**会合。缘由：商机把陈豆给的**预言纸条**随手放在书包里（已在正文补埋：5/12 成绩公布那场 + 6/2 送考那场），之后某刻偶然发现自己的异能能让纸条感应到陈豆方位，两人循指示走进秦岭。
- **旺仔线（阶段一，2026-10-21 作者拍板）**：从宝吉市出发，共**两个副本**（宝吉市 → 回夕海途中一个），宝吉副本里要有其他配角；紫光石给了途中遇到的**其他幸存者（新角色）**；阶段一结束时**已回到夕海，是第一个到夕海的人**，不与其他线会合。**着墨较少**：时间跳跃，每次镜头转到旺仔，用"这几天来，旺仔已经……"式压缩概述让读者知道他的状态即可，不写过细。 **作者 2026-10-23**：旺仔睡前没关窗，受了光雨，已到一阶，能力‘天马行空’被动，自己不知道，读者目前也不知道（伏笔 #26）；"回夕海"的念头要等他先搞清楚现状（末世是真的、提前两年，没人在乎高考了）才出现。
- **商络的"红雾"（2026-10-21 作者拍板）**：商机+胖子线草稿里的红雾保留，但**只是商络地区的特例**，成因待补，由商络市区这个中型副本承担；全球层面仍是无形进化能量 + 凌晨七彩光雨，杀丧尸得紫气。商机线草稿已改为**贴商机的第三人称**、其余以主线为准，经作者逐项确认后于 2026-10-21 并入正文第 12–14 章。

## 4. 与作者协作的约定（务必遵守）

1. **一次只问一个大的方面**，最多拆成 3 个小点；作者说过，问多了他回答会乱。
2. **先落盘，再提下一个问题**。作者回答后，先把结论写进对应 canon 文件，再继续。**绝不在没有真正写入文件的情况下说"已记录"**（上一个 session 犯过这个错，被发现后补写并向作者道歉）。写完可用 grep 核对。
3. 来源要标清：`作者拍板`（带日期）/ `【建议】` / `【待补充】`。没经作者确认的内容不要写成已定。
4. 新决定与旧内容冲突时，**在旧条目处标 ⚠️ 并注明"待重排"，不要静默覆盖**。
5. 作者是写作小白：提问时附上已知条件，必要时给一个草稿让他挑毛病，但不要替他做决定；他否定草稿是正常的，按他的反馈改。
6. 作者的真实朋友是主角原型：涉及主角性格的内容尽量向作者确认，鼓励他补充现实特质。
7. 修改已有正文走"改旧的"流程：先影响面分析师出报告，作者确认范围后才动手（纯代词替换这类零连带影响的小改动，作者可直接批准）。
8. **创意和方案默认由"资深小说家"子 agent 出**（作者 2026-10-22 定）。讨论创意、完善大纲、想剧情时，主控不自己编方案，用 Agent 工具起资深小说家子 agent，让它读 canon 和技法库，返回方案和"技法使用记录"；主控如实转给作者。详见 WORKFLOW 2.7。调用不了就明说，不要假装用了。
9. 涉及 GitHub/账号/密码/密钥等操作要谨慎：不替作者输入密码，不改账号安全设置，推送到哪个仓库先确认。
