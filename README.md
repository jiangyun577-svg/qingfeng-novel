# 末世清风 · 创作系统说明

这个文件夹是《末世清风》的创作工作区：canon 事实源文件 + 9 个专家 skill，供后续续写、修订、灵感讨论时使用。

> 各专家如何配合（尤其是当前的"大纲完善阶段"）见 [WORKFLOW.md](WORKFLOW.md)。

## 文件地图

| 文件 | 作用 | 由谁维护 |
|---|---|---|
| `末世清风1-11.docx` | 用户提供的原始手稿（第1-11章），只读存档，不再修改 | — |
| `moshi-qingfeng-bible.md` | 作者在 Claude 网页版 Artifacts 迭代14版的协作"圣经"，只读存档；v0.5 内容已拆分合并进下方四个 canon 文件 | — |
| `正文.md` | **唯一权威正文版本**，已导入前11章内容；此后所有新写/修订都发生在这里 | 主笔 |
| `大纲.md` | 已完成阶段概要 + 当前状态 + 待定方向 | 大纲架构师 |
| `设定集.md` | 世界观规则（进化体系、地理、货币等） | 设定管理员 |
| `人物表.md` | 每个人物的设定、性格弧光、当前进度 | 人设弧光守护者 |
| `伏笔清单.md` | 已埋设/回收中/已回收的伏笔追踪表 + 每章节奏设计 | 伏笔/节奏设计师 |
| `变更记录.md` | 每轮创作/修订后的审计日志 | 归档员 |
| `.claude/skills/*/SKILL.md` | 9 个专家角色的具体行为说明 | — |

> 提醒：原始 docx 没有章节标题或分页标记，`正文.md` 因此无法自动标注精确的"第几章"。后续新写的内容请按 `## 第N章 · 标题` 的格式追加，方便检索。

## 三种创作模式

### ① 写新的（续写）
在你已经对现有正文/大纲/设定满意的前提下，继续往后写。调用顺序：

1. 大纲架构师 → 更新 `大纲.md`
2. 设定管理员、人设弧光守护者、伏笔/节奏设计师（可并行）→ 分别更新各自文件
3. 逻辑校验官 → 交叉检查以上产出，出具校验报告
4. 主笔 → 读取以上所有结论 + 正文最后几章，只输出正文，追加进 `正文.md`
5. 归档员 → 读取新写的正文，把状态变化写回 `大纲.md` / `人物表.md` / `伏笔清单.md`，并在 `变更记录.md` 记一笔

### ② 改旧的（修订）
你对上一轮某处（正文/大纲/设定的一处或多处）不满意，需要修改：

1. 影响面分析师 → 只出具"影响范围报告"，**不做任何修改**，等待你确认范围
2. 你确认范围后，按报告涉及的层面调用对应专家的"修订模式"（大纲架构师/设定管理员/人设弧光守护者/伏笔节奏设计师/主笔）
3. 归档员 → 收尾同步，`变更记录.md` 留痕

### ③ 讨论灵感
你还没想好接下来写什么，只是想聊聊：

1. 资深小说家 → 只读 canon 文件，纯讨论，不改动任何东西
2. 如果讨论出一个你认可的方向，资深小说家会给你一句"灵感种子"
3. 把这句灵感种子交给大纲架构师，进入模式①

## 使用方式

这些 skill 文件遵循 Claude Code 的 SKILL.md 格式，放在 `.claude/skills/<name>/` 下。如果你以后把 `qingfeng` 作为 Claude Code 的工作目录打开，这 9 个 skill 会被自动发现，可以直接用 `/大纲架构师` 之类的方式（或对应的英文 slug）调用；当前会话里则通过 Agent/Task 的方式手动指定对应 skill 的 prompt 内容来驱动同样的分工。
