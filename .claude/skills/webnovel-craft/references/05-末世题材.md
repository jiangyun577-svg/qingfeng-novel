# 末世题材

## 一、四条铁律

1. **资源永远不够**，每一次得到都要有代价。
2. **信任是最稀缺的东西**，陌生人不该被轻易相信。
3. **没有真正安全的地方**，任何看似的避风港都可能失守。
4. **旧世界的道德不再适用**，新世界需要自己的规矩。

第四条正好扣我们全书的主题"秩序的崩塌与重建"：旧秩序的残影怎么崩，新秩序的雏形怎么长出来，可以做成每个副本的暗线。

## 二、资源张力分级

- **S 级（水、药、电）**：竞争最激烈，人愿意付任何代价。
- **A 级（食物、弹药、庇护所）**：需求高，但可以交易。
- **B 级（衣物、工具、燃料）**：按需分配。
- **C 级（奢侈品、旧货币）**：基地稳定之后才有意义。

本书的世界里，现代科技基本失效（电、车、通讯），食物保质期被进化的微生物大幅缩短，所以"水、药、能吃的东西、能用的冷兵器"是核心。

## 三、幸存者团体的几种原型（给配角和势力用）

| 原型 | 靠什么凝聚 | 剧情作用 |
|---|---|---|
| 军阀 | 武力 | 反派，或脆弱的临时盟友 |
| 信仰团体 | 共同的信念 | 可疑的避风港，也可能是隐藏的威胁 |
| 科学家 | 研究成因或解药 | 希望所在，也最脆弱 |
| 普通难民 | 抱团取暖 | 主角要保护的人，也是人性的试金石 |
| 掠夺者 | 不生产，只拿 | 流动的威胁，标准敌人 |
| 守规矩的体制残余 | 预案、登记、条例 | 旧秩序的残影，规矩救过人，也会把人困死 |

最后一类是我们这本书特别有戏的：用"按规矩办事"的人当对手，没有绝对的坏人，却能写出悲剧。

## 四、常用节拍（可组合）

物资搜寻和它逼出的取舍；决定信谁，信错的代价；发现"安全"的据点其实已经被攻破；与理念不同的团体结盟；内部有人隐瞒感染；规矩把人救了又把人害了；一次小小的善意换来意外的后果。

## 五、可以借鉴的"副本设计"手法（来自无限流）

- 好的副本有**清楚的规则**，并且规则里留有**合理的漏洞**，漏洞就是主角的优势。
- 至少有两种过关方式（硬来、动脑、钻规则）。
- 难度要和主角当下的实力匹配。
- 巧思手法：**信息垄断**（主角知道一条别人不知道的隐藏规则，陈豆的重生信息就是这个）、**借刀杀人**（让环境替主角解决敌人）、**规则叠加**（两条规则合在一起产生意外效果）、**咬文嚼字**（一句含糊的规则主角有不同的理解）。
- 副本里要有隐藏任务或隐藏收获，让人想回头重读。

## 六、本类题材的坑

- 太早出现免费的资源或太容易信任的陌生人，稀缺感和信任感就塌了。
- 反派太蠢，难度不匹配。
- 每个团体都是"坏人"或每个团体都是"好人"，缺少层次。
- 为了笑而削弱危险的真实感：喜剧要建立在别人的难上，而不是把难取消。
- 规则前后不一致，读者会出戏。
