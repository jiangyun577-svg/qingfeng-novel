# 去AI味

## 一、作者明确的要求（优先级最高）

- **不要用破折号"——"**，聊天回复、文档、正文都包括。
- 文风贴近作者的网文口语，句子朴素，不要写得工整，不要总结式的金句。
- 作者说"三两句话"，就只写三两句。
- 技能名用单引号，如‘凝爆’‘屏蔽’。

## 二、常见的AI腔，分几类

| 类型 | 表现 | 怎么改 |
|---|---|---|
| 说教式结尾 | 一段写完非要点题，"这让他明白了……" | 删掉，让场面自己说话 |
| 总结腔 | 每段末尾一句概括，每章末尾一句升华 | 删，停在动作或对话上 |
| 过度工整 | 三段排比、对仗、每段一样长、一样的句式 | 打乱，长短不一，有一处不整齐更真实 |
| 转折套路 | "看似……实则……""不是……而是……"一路用 | 只在确实有信息量时才用 |
| 空洞形容 | 堆形容词和成语，"仿佛""宛如""如同"连用 | 换成一个具体的细节 |
| 量化比喻 | 把感受硬量化，"心中涌起一股难以言喻的……" | 写具体的动作和反应 |
| 对话僵硬 | 每个人说话都像书面语，信息倾倒，礼貌过度 | 短句、打断、各自的口癖 |
| 全员一个腔 | 换个名字就看不出谁在说话 | 回到人物表的口癖栏 |
| 重复与退化 | 逐字重复、循环、残留占位符 | 通读发现并删 |

## 三、标点

- 破折号"——"一律不用，改成逗号、句号或重写句子。
- 省略号只在需要拖长的语气里用一次，不要满篇"……"。
- 引号、感叹号保持作者原有习惯，不要擅自"规范化"。

## 四、改写时的边界

- **保留作者的声音、事实、情节、角色的选择和揭示顺序**，只动措辞。
- 压缩没用的过程，把已有的对峙和判断写得有戏，补上缺失的因果；**不要靠新增小动作、脏话、编造的证据或额外冲突去"假装真实"**。
- 涉及情节改动（事件、动机、结果、新条件）要先给作者看方案，作者同意再改。

## 五、自查顺序

1. 先查破折号。
2. 再查每段末尾是不是在总结。
3. 再看对话是不是都一个腔。
4. 最后通读一遍，看有没有哪里读起来太"顺"、太"整"。顺和整往往就是AI味。
